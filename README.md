# DevOps-Week-02 Application

## Project Overview
Source code management and branch workflow exercise for Junior DevOps Engineers.

## Repository Structure
- `app.py`: Main application script with auth and DB connection logic.
- `database.py`: Database query handlers.
- `config.py`: Environment configuration variables.
- `.gitignore`: Ignore log files and environment files.
- `README.md`: Project documentation.

## Git Workflow & Branch Strategy
- `main`: Production-ready branch.
- `danish-user`: Authentication implementation branch.
- `ahmad-user`: Database configuration branch.
- `docs-update`: Documentation PR branch.
